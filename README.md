# About the repo
This repo contains 2 map files: one labeled v7 and one using a traditional update numbering scheme (1.1, 1.2, etc.). The map file labeled v7 is for build 146 of Mindustry, the outdated version of the game. If for whatever reason you're still using v7, download that file. Mindustry v7 is no longer receiving changes and as such I will no longer be updating the v7 map.

The numbered map is the one I am actively supporting. It should be functional for the latest stable Mindustry version, currently v8 or build 159 (if it's not, send me a message on Discord. My username is "deepspacerunner (ok to ping)").


# Installing the map
To install the map, first download the map file. Do this by clicking on the "Releases" text on the right side of the page. Then click on the appropriate for your Mindustry version, as seen above. Your browser will notify you that you've downloaded the file. Then open Mindustry, go to the Editor tab of the main menu, and press Import Map at the bottom of the Editor menu. Select the map file. You should now see the map appear in your Editor tab. Go back to the main menu, out of the Editor tab. Click Play. Click Custom Game. Select the map. Choose Sandbox Mode and hit Play.

## Help! The map is not installing!
First, ensure you have downloaded the correct version. See above in "About the repo" to determine which is correct.

If you recieved an error that looks like this:
```
Error loading file.

(Incorrect header check)

> Zip: 'incorrect header check'

InflaterInputStream.read:181
```

Then you may have downloaded the HTML of the file page instead of the file. Either click on the "releases" section of the repo at the right side of your screen and select the correct version, or click on "download raw" at the page that has a toggle between "code" and "blame" accessed by clicking on the file name on the home repository page.
